# Smart Classroom & Timetable Scheduler

The project is designed to generate conflict-free and resource-aware timetables while considering real-world academic constraints such as faculty availability, classroom capacity, laboratory requirements, multiple college shifts, and student transportation timings.

---

##  Project Overview

Manual timetable preparation can lead to:

- Faculty clashes
- Classroom and laboratory conflicts
- Section/batch clashes
- Uneven faculty workload
- Poor classroom utilization
- Long student idle periods
- Problems caused by different college shifts
- Students waiting unnecessarily for college buses

This project aims to solve these problems using **Data Structures, Algorithms, and Object-Oriented Programming**.

---

## Objectives

- Generate optimized college timetables automatically
- Prevent faculty, room, lab, and section conflicts
- Manage multiple classrooms and laboratories
- Support different daily college shifts
- Consider college bus departure timings
- Reduce unnecessary student idle/waiting time
- Balance faculty workload
- Improve classroom utilization
- Generate multiple valid timetable options
- Suggest alternative arrangements when conflicts occur

---

## Key Features

### 1. Timetable Generation

Automatically assign:

- Subjects
- Faculty
- Sections
- Rooms
- Laboratories
- Days
- Time slots

while respecting defined constraints.

### 2. Smart Classroom Management

Maintain information about classrooms and laboratories, including:

- Room number
- Capacity
- Type
- Available equipment
- Availability
- Lab/classroom status
